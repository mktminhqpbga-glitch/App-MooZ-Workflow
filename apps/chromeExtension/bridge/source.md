# Adapter source and license

These browser adapters come from MooZ Connect Native 2.0.0, preserved from
`mktminhqpbga-glitch/App-MooZ-Workflow` at commit
`d1e8373134453e84588833b778c74a3e78944162`. The companion was generated by
`native/Tools/build_companion.py` from `downloads/MooZ-Connect.zip`; the original
sources and notices remain available in that Git history and in the local backup.

File names were converted to camelCase for this repository. The new worker and
relay transport replace the old desktop transport. The inherited Muse DOM
adapter has not been accepted against a live Muse account in this fork.

This separately distributed Chrome extension, including its adapter and glue,
is provided under GPL-2.0-or-later; see `license.txt`. The Toonflow upstream
application retains its MIT license. No browser account cookies are part of the
source or distribution.
